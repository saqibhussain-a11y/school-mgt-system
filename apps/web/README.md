# apps/web

The Next.js 16 (App Router) frontend for the School Management System —
both the tenant dashboard (`/dashboard/*`) and the Platform Admin console
(`/platform/*`), in one app.

This package isn't run or set up on its own — see the
[root README](../../README.md) for tech stack, every module, environment
variables, local setup on macOS/Windows, and the full deployment guide.

Quick reference, once the monorepo is set up:

```bash
npm run dev -w apps/web    # or: npm run dev:web from the repo root
```
